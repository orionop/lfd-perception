# Archived: manuscript / research-paper workstream ("B")

**Status: archived, 2026-09-10. Not being pursued. Kept for reference only —
not deleted.**

## Why

The sole active focus of this repository is: **vision-based recognition of
objects relevant to robot tasks, extracted from task demonstration data**
(Deliverable A). The manuscript/paper workstream, along with the
wrench/force-calibration investigation that partly motivated it (see
`../wrench_force_calibration/`), consumed significant time without producing
anything the lab deliverable needs. It is parked, not deleted, in case it's
worth resuming later.

- `Docs/wrench2role-paper.tex` (+ `.pdf`) — the canonical prospective paper

## If this is ever resumed

Nothing here blocks or is blocked by the active deliverable work — `Code/`'s
production pipeline has no dependency on anything in this directory.
Re-read `MANUSCRIPT_B.md`'s evidence gates before resuming; they were
written specifically because the earlier draft's claims outran what had
actually been measured at the time.
